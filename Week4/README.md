# Iris Flower Classification with Decision Tree

This project explores the classic Iris dataset and uses a Decision Tree Classifier to classify flowers into three species: Setosa, Versicolor, and Virginica.

## Project Summary

- Loaded the Iris dataset from the provided CSV file.
- Explored the structure of the dataset and the distribution of its features.
- Used visualizations such as box plots to understand the spread of sepal and petal measurements.
- Split the data into training and testing sets.
- Trained a Decision Tree Classifier.
- Evaluated the model using accuracy, confusion matrix, and classification report.

## Dataset Details

- Dataset: Iris Flower Dataset
- Total Records: 150 samples
- Features: sepal length, sepal width, petal length, and petal width
- Target Variable: species

## Workflow

1. Importing the required libraries.
2. Loading and inspecting the dataset.
3. Preparing the feature and target variables.
4. Splitting the data into train and test sets.
5. Training the model.
6. Evaluating the results.

## Conclusion

This notebook demonstrates how a simple decision tree classifier can effectively identify iris flower species from physical measurements. It is an excellent introductory project for understanding classification workflows in machine learning.
