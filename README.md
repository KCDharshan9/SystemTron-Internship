# SystemTron Internship of Data Science

This repository contains projects completed during the SystemTron data science internship.

## Week 1
- A Week 1 project focused on movie rating prediction using Python and pandas.
- Includes data exploration, preprocessing, and a machine learning model workflow.
- Work is based on the TMDB movie dataset and aims to predict ratings from movie features.
- Project files include `app.py`, a Jupyter notebook, and related datasets.
- [Check out the app here!](https://filmfinder9.streamlit.app/)

# Week 2
- Week2 focuses on Titanic dataset analysis and EDA using pandas, seaborn, and matplotlib.
- Cleaned data, handled missing values, and explored survival factors like passenger class, age, and sex.
- Visualized key relationships to understand which features affect survival.
- Includes a few main charts saved in the `images` folder for quick reference.
